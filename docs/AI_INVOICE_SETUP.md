# قراءة فواتير الشراء بالذكاء الاصطناعي

الميزة تستخدم Lovable AI Gateway داخل Server Function محمية، لذلك لا تحتاج إلى مفتاح OpenAI خاص ولا يظهر أي مفتاح في المتصفح.

## إعداد الخدمة

لا توجد خطوات لإضافة `OPENAI_API_KEY`. Lovable ينشئ ويدير مفتاح `LOVABLE_API_KEY` تلقائيًا داخل بيئة الخادم عند تفعيل Lovable AI Gateway للمشروع.

بعد نشر التطبيق من Lovable، افتح صفحة **فاتورة شراء جديدة** واضغط **قراءة الفاتورة بالذكاء الاصطناعي** ثم **اختبار الاتصال**.

الصور الكبيرة يتم تصغيرها وضغطها في المتصفح قبل إرسالها إلى Server Function. يمكن رفع صورة أو PDF متعدد الصفحات، ثم يجب مراجعة النتائج قبل إضافتها إلى الفاتورة.

لا تضع أي مفتاح في `.env` الخاص بالواجهة أو داخل أي ملف يتم رفعه إلى GitHub.
