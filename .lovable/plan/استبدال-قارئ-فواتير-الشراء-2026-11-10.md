# استبدال قارئ فواتير الشراء

## ما سيتغير
- نقل تحليل صور وملفات PDF من خدمة OpenAI الحالية إلى Lovable AI.
- الإبقاء على شاشة رفع الفاتورة ومراجعتها، ربط المورد، إرفاق الملفات، وحفظ المشتريات كما هي.
- دعم عدة ملفات/صفحات مع استخراج بيانات المورد والفاتورة والإجمالي وبنود المنتجات والباركود عند وضوحه.
- عرض حالة اتصال مناسبة ورسائل عربية واضحة عند فشل التحليل أو نقص الإعداد.

## التفاصيل التقنية
- استخدام AI Gateway SDK داخل وظيفة خادم TanStack محمية بتسجيل الدخول، وإرجاع نتيجة JSON مُتحقق منها.
- التحقق من نوع الملفات وحجمها وعددها قبل طلب التحليل، وإرسال صفحات الصور وPDF إلى نموذج متعدد الوسائط يدعم واجهة Responses.
- إزالة اعتماد قارئ الفواتير على Supabase Edge Function و`OPENAI_API_KEY` دون تغيير قاعدة البيانات أو تخزين المرفقات.
- التحقق من أنواع النموذج المولّدة، وفحص الأنواع والبناء وسجل البناء بعد التعديل.
